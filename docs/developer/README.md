## 🎯 Empezar Ahora

### Para Integrar Agentes Externos
1. Lee [Quick Start Guide](QUICK_START.md)
2. Elige tu SDK: [Python](SDKS/SDK_PYTHON.md) | [TypeScript](SDKS/SDK_TYPESCRIPT.md) | [Java](SDKS/SDK_JAVA.md)
3. Sigue el ejemplo de [Agentes Externos](CASOS_USO/AGENTES_EXTERNOS.md)

### Para Crear Plugins
1. Lee [Guía de Plugins](PLUGINS/GUIA_PLUGINS.md)
2. Revisa [Cómo Funcionan los Plugins](PLUGINS/COMO_FUNCIONAN.md)
3. Sigue [Ejemplo Completo](PLUGINS/EJEMPLO_COMPLETO.md)

### Para Conectar Agentes vía MCP
1. Lee [Introducción MCP](MCP/INTRODUCCION_MCP.md)
2. Configura [MCP Server](MCP/GUIA_MCP.md)
3. Conecta tu agente (Claude, ChatGPT, etc.)

### Para Extender con Procesos/Pantallas/Reglas
1. Lee [Plugins Completos](PLUGINS/PLUGINS_COMPLETOS.md)
2. Revisa [Plugin Model](PLUGINS/PLUGIN_MODEL.md)
3. Sigue ejemplos en [Workflows](CASOS_USO/WORKFLOWS.md)
