# Changelog - CodeflowX Developer Portal

Historial de cambios y versiones.

---

## [1.0.0] - 2025-01-XX

### Añadido
- SDKs Python, TypeScript y Java
- Sistema de plugins (simples y completos)
- Developer Console
- Especificación MCP
- Documentación completa

### SDKs
- Registro de agentes
- Telemetría
- Memoria centralizada
- Supervisor
- Compliance
- Policy Runtime
- Resiliencia (retry, circuit breaker, rate limiting)
- Caché y offline mode
- Filtrado PII
- Métricas

### Plugins
- Plugins simples (HOOKS_ONLY) con hooks MCP
- Plugins completos (FULL_EXTENSION) con procesos BPMN, pantallas ZKoss y reglas Drools
- Sistema de carga y validación
- Sandbox para ejecución

### Developer Console
- Gestión de plugins
- Gestión de API keys
- Visualización de logs
- Playground para testing
