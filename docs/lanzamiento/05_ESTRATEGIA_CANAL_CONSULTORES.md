# 🤝 ESTRATEGIA CANAL CONSULTORES Y AGENCIAS
## Programa Partners - Crecimiento Escalable sin Sales Team Grande

**Target:** Consultores independientes + Pequeñas consultoras (2-20 personas) + Agencias marketing IA  
**NO Target:** Grandes consultoras (Accenture, Deloitte, etc.) - Fase posterior

## 🎯 POR QUÉ CANAL CONSULTORES

### **Ventajas Estratégicas:**

**1. Escalabilidad Sin Headcount**
```
✅ Cada partner = 1 sales person "virtual"
✅ 20 partners = 20 sales people
✅ Sin coste fijo nómina
✅ Solo pagas comisión si venden
```

**2. Credibilidad Pre-Built**
```
✅ Consultores ya tienen confianza de clientes
✅ Relaciones existentes
✅ Expertise reconocido
✅ Nosotros aprovechamos su red
```

**3. Expertise Complementario**
```
✅ Ellos: Estrategia, consultoría, implementación procesos
✅ Nosotros: Plataforma técnica, producto
✅ Win-win: Cliente recibe solución completa
```

**4. Velocity Mayor**
```
✅ Consultores cierran más rápido (relación previa)
✅ Menos fricción venta
✅ Menos objeciones (trusted advisor)
```

## 💰 MODELO ECONÓMICO PARTNERS

### **Comisión Estructura:**

**Opción A: Comisión Recurrente (Recomendado)**
```
20% revenue mensual mientras cliente activo

Ejemplo:
- Cliente paga 1000€/mes
- Partner recibe 200€/mes
- Duración promedio cliente: 24 meses
- Total partner por cliente: 4800€

Ventaja: Ingresos pasivos recurrentes partner
```

**Opción B: One-time + Menor Recurrente**
```
25% primer pago + 10% recurrente

Ejemplo:
- Cliente paga 3000€ setup + 1000€/mes
- Partner recibe: 750€ (primer pago) + 100€/mes después
- Total 24 meses: 3150€

Ventaja: Cash upfront para partner
```

**Elegir:** Opción A (incentiva retención cliente, relación long-term)

### **Calculadora ROI Partner:**

**Consultor Independiente:**
```
Escenario Conservador:
- 3 clientes/año × 1000€/mes × 20% = 600€/mes = 7.2K€/año
- Esfuerzo: 10-15h venta/onboarding por cliente
- Hourly rate implícito: ~150-200€/h

Escenario Optimista:
- 10 clientes/año × 1500€/mes × 20% = 3000€/mes = 36K€/año
- Revenue pasivo significativo
```

**Pequeña Consultora (10 personas):**
```
Escenario Conservador:
- 10 clientes/año × 1000€/mes × 20% = 2000€/mes = 24K€/año
- 1 persona dedicada part-time

Escenario Optimista:
- 30 clientes/año × 2000€/mes × 20% = 12K€/mes = 144K€/año
- 1 persona full-time + comisiones = ROI positivo
```

**Agencia Marketing:**
```
Escenario:
- 5 clientes (sus propios clientes) × 1000€/mes × 20% = 1000€/mes = 12K€/año
- Esfuerzo marginal (clientes existentes)
- Pure margin adicional sin coste venta
```

## 🎯 LEAD MANAGEMENT

### **Flujo Leads Partner:**

**Paso 1: Partner Identifica Lead**
```
→ Partner tiene contacto cliente potencial
→ Valida fit básico (usa IA, necesita compliance)
```

**Paso 2: Registro Lead en Portal**
```
→ Partner registra lead en portal partners
→ Campos: Empresa, contacto, sector, oportunidad estimada, fecha cierre esperada
→ Lead asignado automáticamente a partner (protección 90 días)
```

**Paso 3: Partner Trabaja Lead**
```
→ Discovery call
→ Demo (partner solo, o co-demo con CodeflowX)
→ Propuesta
→ Negociación
```

**Paso 4: Cierre**
```
→ Cliente firma contrato
→ Partner notifica en portal
→ Onboarding cliente (partner + CodeflowX)
→ Comisión activa desde primer pago
```

**Paso 5: Renovación**
```
→ Partner responsable retención (incentivo comisión recurrente)
→ Check-ins regulares con cliente
→ Upsell oportunidades (más licencias, más módulos)
```

## 🛡️ PROTECCIÓN LEADS (Deal Registration)

### **Reglas:**

**1. First Come First Serve**
```
- Primer partner registra lead → Lead asignado a ese partner
- Protección 90 días
- Si partner no cierra en 90 días → Lead liberado
```

**2. Excepciones:**
```
- Cliente inbound directo web → No asignado a partner (CodeflowX direct)
- Cliente ya contactado por CodeflowX antes → No asignado
- Cliente rechaza explícitamente partner → Lead liberado
```

**3. Disputas:**
```
- Si 2 partners reclaman mismo lead → Review caso por caso
- Criterio: Quién tuvo relación previa con cliente
- Decisión final: Manuel
```
